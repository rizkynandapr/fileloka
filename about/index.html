About Fileloka

A small set of file tools built on one rule: the file stays on your device.

Why it exists

Most free PDF and image sites work the same way. You upload the file, their server processes it, and you trust them to delete it afterwards. That's a lot of trust to hand over for a payslip, an ID scan or a signed contract.

Fileloka does the same jobs inside your browser. Nothing is uploaded, so the question of what happens to your file on someone's server never comes up.

Who runs it

Fileloka is built and maintained by Rizky Nanda Praditia, an independent developer in Indonesia. There is no company or investor behind it.

How it stays free

Your device does the processing, so running the site costs little. Every tool works in full without an account, a watermark or a daily limit, and the tools that are free today stay free.

Open source

The code is public on GitHub under the MIT licence, so anyone can check that it does what this page says.

It stands on other people's open-source work: pdf-lib, PDF.js, JSZip, qrcodejs and libheif-js. Each one is bundled with the site at a fixed version and keeps its own licence.
