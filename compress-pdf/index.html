Questions about this tool

How small will my PDF get?

It depends on what's inside. Scanned or photo-heavy PDFs often shrink 50–90%. Text-only PDFs are already compact and may barely change — the size meter shows you the honest before/after numbers.

How do I compress a PDF to a specific size like 200 KB?

Choose Target size, pick 200 KB (or type any size), and press Compress. Fileloka tries the text-preserving method first, then searches for the highest image quality that still fits — you don't have to guess with sliders.

What's the difference between Smart and Maximum?

Smart only recompresses the images embedded in the PDF, so text, links and vector graphics stay exactly as they were. Maximum redraws every page as an image — the smallest result, but text can no longer be selected or searched.

Is it safe to compress confidential PDFs here?

Yes. Compression happens on your device; the file is never transmitted. That's a structural guarantee, not a policy promise — there is no server that could store or leak it.
