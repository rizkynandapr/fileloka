Kompres foto tanpa merusak tampilannya

Kecilkan ukuran foto secara drastis — untuk formulir online yang membatasi ukuran, lampiran email, atau supaya website-mu cepat — sambil tetap terlihat tajam. Bisa banyak file sekaligus, dengan penghematan per file ditampilkan jujur. Bonus privasi: metadata EXIF (lokasi GPS, tipe kamera) ikut terhapus otomatis.

Cara pakai

  1. Pilih atau jatuhkan satu atau banyak foto sekaligus.
  2. Atur kualitas, format keluaran (JPG, WebP, atau format asli), dan lebar maksimum bila perlu.
  3. Kompres, lalu unduh per file atau semuanya dalam ZIP — lengkap dengan ukuran sebelum/sesudah.

Pertanyaan seputar alat ini

Bagaimana cara kompres foto jadi 100–200 KB?

Pakai format JPG dengan kualitas sekitar 70%, dan isi “lebar maksimum” misalnya 1200–1600 piksel — kombinasi keduanya yang paling menentukan. Angka hasil tiap foto ditampilkan, jadi kamu bisa menyesuaikan sampai pas di bawah batas formulir.

Kenapa foto PNG saya tidak mengecil?

PNG itu format lossless, jadi slider kualitas tidak berlaku. Solusinya: isi lebar maksimum untuk memperkecil dimensinya, atau ubah formatnya ke JPG/WebP — penyusutannya langsung besar.

Apa itu metadata EXIF dan kenapa dihapus?

EXIF adalah data tersembunyi di dalam foto: titik GPS tempat foto diambil, tanggal, dan tipe HP/kamera. Saat foto dikompres ulang ke JPG atau WebP, data ini otomatis terbuang — lebih aman kalau fotonya akan dibagikan ke publik.

Apakah foto saya di-upload untuk dikompres?

Tidak — kompresi memakai mesin gambar milik browser-mu sendiri. Karena tidak ada proses upload, hasilnya juga jauh lebih cepat: tidak ada antrean menunggu server.
