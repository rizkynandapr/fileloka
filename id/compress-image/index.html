Kompres foto tanpa bikin pecah

Kecilkan ukuran foto buat formulir online, lampiran email, atau website yang lebih cepat. Bisa banyak sekaligus, lebarnya bisa dibatasi, dan penghematan tiap file ditampilkan.

Cara pakai

  1. Pilih satu atau beberapa foto, atau seret ke halaman ini.
  2. Atur kualitas, format hasil (JPG, WebP, atau tetap), dan lebar maksimal kalau perlu.
  3. Kompres, lalu unduh per file atau sekaligus dalam ZIP. Ukuran sebelum dan sesudah ditampilkan.
IklanSatu iklan ini yang membayar biaya hosting.

Pertanyaan soal alat ini

Bagaimana cara kompres foto jadi di bawah 200 KB?

Pilih format JPG, turunkan kualitas ke sekitar 70 persen, dan isi lebar maksimal (misalnya 1200 px). Hasil tiap file langsung kelihatan. Kalau masih kebesaran, turunkan lagi sedikit.

Seberapa kecil hasilnya?

Foto dari HP biasanya menyusut 60 sampai 90 persen di pengaturan bawaan, dan di layar tampilannya tetap sama.

Kenapa PNG saya tidak mengecil?

PNG itu lossless, jadi slider kualitas tidak berpengaruh. Isi lebar maksimal untuk memperkecil dimensinya, atau ubah ke JPG atau WebP supaya jauh lebih kecil.

Foto saya di-upload?

Tidak. Kompresi dilakukan mesin gambar bawaan browser di perangkatmu. Bonusnya, data EXIF seperti lokasi GPS ikut dibuang saat disimpan jadi JPG atau WebP.
