Pisah PDF dan ambil halaman yang kamu butuhkan

Ambil halaman atau rentang tertentu dari PDF (misalnya 1-3 dan 7), atau simpan setiap halaman jadi file sendiri. Semuanya diproses di perangkatmu, jadi isi dokumen tidak pernah dilihat server mana pun.

Cara pakai

  1. Pilih PDF yang mau dipisah, atau seret ke halaman ini.
  2. Pilih mode: ambil rentang halaman (contoh 1-3, 7) atau jadikan tiap halaman PDF sendiri.
  3. Unduh hasilnya. Kalau filenya banyak, semuanya dijadikan satu ZIP.
IklanSatu iklan ini yang membayar biaya hosting.

Pertanyaan soal alat ini

Bagaimana cara ambil satu halaman saja dari PDF?

Pilih mode 'Ambil halaman', ketik nomor halamannya (5 saja, 2-4, atau gabungan seperti 1-3, 7), lalu unduh. Kamu dapat PDF baru yang isinya cuma halaman itu.

Bisa pecah PDF jadi satu file per halaman?

Bisa. Pilih 'Setiap halaman jadi PDF sendiri' dan kamu dapat ZIP berisi PDF bernomor, satu per halaman. Praktis buat memecah hasil scan.

Teksnya masih bisa dicari setelah dipisah?

Masih. Halamannya disalin, bukan difoto ulang, jadi teks tetap bisa diseleksi, dicari, dan di-copy.

Dokumen saya di-upload waktu diproses?

Tidak. File dibaca ke memori browser, dipisah di situ, dan hilang begitu tab ditutup. Internet diputus setelah halaman terbuka pun alatnya tetap jalan.
