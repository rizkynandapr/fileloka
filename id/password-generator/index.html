Buat password kuat yang benar-benar acak

Hasilkan password yang benar-benar acak memakai mesin kriptografi browser — panjang, jenis karakter, dan filter karakter mirip semua di tanganmu, lengkap dengan meteran entropi yang jujur, bukan sekadar warna “kuat/lemah”.

Cara pakai

  1. Atur panjang (disarankan 16+) dan jenis karakter yang mau dipakai.
  2. Aktifkan “hindari karakter mirip” (l, 1, O, 0) untuk password yang akan diketik manual.
  3. Salin password-nya — setiap perubahan pengaturan langsung membuat password baru.

Pertanyaan seputar alat ini

Seberapa aman generator ini?

Memakai crypto.getRandomValues — sumber acak kriptografis yang sama dengan yang dipakai aplikasi password manager — dengan sampling tanpa bias dan jaminan setiap jenis karakter terpilih muncul. Kodenya open source, jadi klaim ini bisa diperiksa siapa pun.

Apa arti angka “bit entropi”?

Entropi mengukur seberapa sulit password ditebak paksa. Kasarnya: 45 bit lemah, 70 cukup, 100+ sangat kuat. Password 16 karakter dengan semua jenis karakter ada di kisaran 100 bit — kuat untuk akun apa pun.

Apakah password saya disimpan atau dikirim?

Tidak. Password dibuat di memori browser dan hanya ada di layarmu serta clipboard. Muat ulang halaman, hilang tanpa jejak.

Kapan perlu menghindari karakter mirip?

Nyalakan untuk password yang akan dibaca dan diketik manual (Wi-Fi, TV). Untuk password yang disimpan di password manager, matikan saja supaya kumpulan karakternya sedikit lebih besar.
