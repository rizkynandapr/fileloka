Dibangun terbalik dari situs lain

Situs alat file pada umumnya bekerja begini: file-mu di-upload ke server mereka, diproses di sana, lalu mereka berjanji menghapusnya “beberapa jam kemudian”. Kamu diminta percaya.

Fileloka membalik urutannya: tidak ada server sama sekali. Alat-alatnya diunduh ke browser-mu, lalu bekerja di situ. Buktikan sendiri — buka salah satu alat, aktifkan mode pesawat, dan semuanya tetap berjalan. Itu juga alasan semuanya terasa cepat: tidak ada waktu terbuang untuk upload.

Pertanyaan yang sering diajukan

Beneran gratis? Batasnya apa?

Gratis, tanpa akun, tanpa watermark, dan tanpa batas jumlah pemakaian. Batas ukuran file pun tidak dibuat-buat — batasnya hanya kemampuan perangkatmu sendiri, karena memang perangkatmu yang bekerja.

Bagaimana saya tahu file saya tidak di-upload?

Dua cara: buka DevTools browser → tab Network saat memakai alat, tidak ada permintaan berisi file; atau setelah halaman terbuka, putuskan internet/aktifkan mode pesawat — alatnya tetap jalan. Kode sumbernya juga terbuka di GitHub.

Bisa dipakai di HP?

Bisa — semua alat berjalan di browser HP (Chrome, Safari) tanpa install aplikasi. Untuk PDF yang sangat besar, laptop memang lebih bertenaga, tapi pemakaian sehari-hari lancar di HP.

PDF yang terkunci password bisa diproses?

Belum. File terenkripsi terdeteksi dan diberi tanda dengan jelas, bukan diproses setengah-setengah. Buka dulu kuncinya, baru proses di sini.

Boleh dipakai untuk keperluan kerja atau usaha?

Boleh sepenuhnya — dokumen kantor, berkas klien, materi jualan. Justru karena tidak pernah di-upload, alat ini lebih pantas dipakai untuk dokumen sensitif dibanding situs yang menyimpan filemu di server mereka.

Privasi, dalam bahasa manusia

Fileloka tidak mengumpulkan apa pun: tidak ada akun, tidak ada cookie pelacak, tidak ada analytics, dan yang terpenting — tidak ada file yang dikirim ke server, karena servernya memang tidak ada. Yang kamu proses di sini sepenuhnya urusan perangkatmu sendiri.
